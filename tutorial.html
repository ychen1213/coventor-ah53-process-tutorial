1．先确认我们做的是什么

mark 是凸出来的 Si，外围是被刻掉的 Si。GDS 上三条矩形表示需要保护的区域。曝光后光刻胶应留在三条矩形上方，周围露出硅；刻蚀后去胶，得到凸条。这里的 AH53 是我们此前建立的“简化单方向教学示例”，不是已经认证的商业 AH53 全版图。

本文对应电脑里的 D:\SEMulator3D9，版本文件确认是 9.3.0.0。菜单依据这套安装随附的官方帮助核查；窗口布局可被用户定制，因此用标签、菜单和字段名定位，不用固定屏幕坐标。

三件事要分开：
① 工艺仿真：SEMulator3D 依据 GDS 和工艺步骤计算 Si/PR 三维形貌。
② 格式转换：读取导出的 VDATA，把已经得到的形貌转换给其他软件；它本身不重新刻蚀。
③ 电磁仿真：Lumerical FDTD 加光源、边界、网格、监视器后求解电磁场。本教程主体完成①及 VDATA 导出；仅打开几何模型不等于完成③。

非理想工艺需要自己设定或用实验标定。软件不会仅凭“Si、300 nm、AH53”自动推断机台气体、压强、功率和真实缺陷。本例是真正执行的原生几何/行为工艺模型，参数用于教学；目前没有真实设备配方和 SEM/TEM 截面来校准其预测精度。

可先只做理想版，理解保凸极性和结果检查；再做非理想版。Multi Etch 属于高级建模功能，本机运行仍须有相应许可。

2．工程文件各有什么作用

文件内容与作用是否已经是结果
.gds / .cat二维版图、多边形、层号与顶层 cell否，没有刻蚀后的三维结构
-layermap.txt把 GDS 数字层映射成工艺 Mask 名称否
.vmpd工艺材料数据库，如 Si_Xtal、Resist否；它不是 FDTD 光学色散库
.vproc工艺步骤、顺序、厚度、刻蚀模型与参数否，是工艺输入
.zamManager 工程：关联输入文件、范围、分辨率和构建状态仅有它不能证明已经构建成功
*-Output / .vwaf原生构建后的阶段状态与 wafer 数据是；启用逐步保存后可看中间形貌
.vdata导出的体素材料/占比与元数据，可选界面平面方程是，需确认导出的是去胶后的正确阶段
.fspLumerical 工程，可仅有几何，也可带求解设置与结果需另查是否真正运行过 FDTD

3．尺寸、单位和模拟范围

下文除专门标注 nm 或角度外，长度输入都用 µm（微米）。换算：1 µm = 1000 nm；300 nm 输入 0.3，20 nm 输入 0.02。

项目教学值意义
Si 厚度1.0 µm初始上表面 Z≈+0.5 µm，下表面 Z≈−0.5 µm
PR 厚度0.5 µm涂胶后胶顶约 Z=+1.0 µm
每条宽 / 长1.6 / 20 µm条纹沿 Y；Y 从 −10 到 +10

理想刻蚀深度0.3 µm凸条顶 +0.5、周围沟底 +0.2，差 300 nm
原先两个结果的范围不同：旧理想版是四组 12 条、72×28 µm；旧非理想完成版是一组 3 条、16×28 µm。不能直接拿两者总 Si 体积比较。本文新脚本默认两种流程都只构建同一组三条，便于对照。脚本生成的 GDS 保留原 12 条上下文，但 DOMAIN 只覆盖这一组；选择 --full-layout 才改成全域构建。

20 nm 下单组 1 µm 厚 Si 的包围网格约 800×1400×50，即 5600 万格。中间 PR 增高、界面、缓存和算法会额外占用内存；不能用最终压缩 VDATA 文件大小推算工艺求解内存。10 nm 相比 20 nm，三维体素数约增加到 8 倍，运行代价可能更高。

4．手动准备窗口、材料与单位

  1. 先在资源管理器新建 D:\CoventorProjects\AH53_Manual_Ideal_01。建议路径用英文和数字，减少旧版软件的路径编码问题。
  2. 打开 SEMulator3D。用 Help > About SEMulator3D 确认版本。用 Window > New 打开独立空窗口，避免替换已经打开的工程。
  3. 在 Window 菜单显示 Manager、Process Editor、Material Library 标签。注意 File > New 作用于当前活动标签，不是一次生成全部依赖文件。
  4. 切到 Material Library，File > Open 打开 D:\SEMulator3D9\apps\SEMulator3DMaterialsDatabase9.vmpd。然后 File > Save As，另存为新目录里的 AH53_manual.vmpd。
  5. 展开材料组，确认存在 /Silicon/Si_Xtal 和 /Organics/Resist。如果使用其他材料库，工艺中必须选真实存在的材料，不要只把名字敲进去。
  6. 切到 Process Editor，File > New。新工艺通常自带第一步 Wafer Setup。
  7. 在 Process Editor 的 File > Properties 中，关联刚才保存的材料库，检查当前工艺 Model Unit = micrometers / µm。Tools > Options 的 Default Model Unit 只影响以后新文件，不能替代检查当前工艺单位。
  8. File > Save As 保存 AH53_manual.vproc。
完成检查：有独立窗口、自己的材料库副本和一个单位为 µm 的工艺文件。此时还没有三维刻蚀结果。

相关官方帮助：材料库 · Process Editor 文件属性

5．从空白手动画 GDS 版图

以下菜单针对本机随附的 SEMulator3D Layout Editor。如果 Manager 配置的是第三方版图软件，菜单会不同。也可以先由后文代码生成 GDS，再从本节末尾的层映射开始。

5.1 新建布局库与顶层 cell

  1. 在 Manager 工具栏点 Launch Layout Editor；或从开始菜单的 Coventor SEMulator3D 9 程序组启动 Layout Editor。
  2. 在 Layout Editor 中选择 File > New > Blank。File > Save As 保存 AH53_layout.cat 到新目录。
  3. 选择 Tools > Units > Microns。不要依赖默认单位。可在 Tools > Options > Grid 设 Working Grid=0.01、Display Grid multiple=50。
  4. 用 Cell > New 创建 cell；需要命名对话框时，可在下方 Command Line 输入 cellcreate -ui on，命名 AH53_DEMO。如果已经有 unnamed cell，也可以画完后 Cell > Save 时命名。
  5. 若当前界面拒绝下划线，统一用 AH53DEMO；后面 GDS 导出和 Manager Top Cell 必须使用同一个名字。此前实际 GDS 的 AH53_DEMO 已成功导入；这里不假定所有旧 GUI 命名对话框行为完全一致。

5.2 创建两层

  1. 用 View > Layers > Browse 打开 Layer Browser。
  2. 在 Layer Browser 自己的 Layer > New 创建层，不是在主菜单里猜一个同名入口。
  3. 第一层：Layer 和 Mask name 均为 AH53_KEEP，GDS 字段填 L1D0，GDS I/O=True。颜色自选。
  4. 第二层：Layer 和 Mask name 为 DOMAIN，GDS 字段 L99D0，GDS I/O=True。范围层建议只显示轮廓，颜色与条纹分开。
  5. 若对话框包含 Mask contribution 与 Mask field polarity，可用 Add、Light。它们是编辑器层属性；真正决定保凸/挖槽的是后面的 Expose Material 工艺极性。

5.3 精确输入四个矩形

选择 Object > Rectangle，Input Mode=Corners。每次确认 Layer，输入两角坐标，然后 Apply；完成后 Close。不要靠鼠标拖拽估计宽度。

对象Layer第一角 (X,Y)第二角 (X,Y)
条 1AH53_KEEP(20.0, −10.0)(21.6, +10.0)
条 2AH53_KEEP(23.2, −10.0)(24.8, +10.0)
条 3AH53_KEEP(26.4, −10.0)(28.0, +10.0)
范围框DOMAIN(16.0, −14.0)(32.0, +14.0)

若习惯命令栏，在单位为 Microns、当前层已选 AH53_KEEP 时，也可依次输入：

rectangle 20 -10 21.6 10
rectangle 23.2 -10 24.8 10
rectangle 26.4 -10 28 10

然后切到 DOMAIN，再输入：

rectangle 16 -14 32 14

5.4 保存并导出 GDS

  1. 先 Cell > Save，再 File > Save。只保存 cell 不能保证整个库已经写入磁盘。
  2. 用 Cell > Summary 检查三条矩形和一个范围框；用 Layer Browser 分别隐藏显示两层，防止误画到同一层。
  3. 选择 File > Translators > Gds Out。Output file 填新目录 AH53_layout.gds；Library 选刚保存的 CAT；Top cell 选 AH53_DEMO；Cell 字段留空；Scale factor=1。Top cell 与 Cell 不要同时填写。
  4. Apply 后 Close。也可 File > Save As，类型选 GDS；明确 Top cell 时优先用上述 Translator。

5.5 写层映射

用记事本新建纯文本 AH53_manual-layermap.txt，内容为：

AH53_KEEP  1  0
DOMAIN     99 0

第一列是工艺掩模名，后两列为 GDS layer、datatype。检查 Windows 没有把文件误存为 .txt.txt。不设映射时也可以用 L1D0、L99D0，但所有工艺引用必须一起改；本教程统一使用 AH53_KEEP、DOMAIN。

完成检查：GDS 中 L1D0 是三条，L99D0 是 16×28 µm 范围矩形。DOMAIN 绝不能被用作条纹保护掩模。

6．连接版图、工艺与 Manager

  1. 回到 SEMulator3D 的 Manager 标签。Analysis or Process File 选 AH53_manual.vproc。
  2. Layout File 选 AH53_layout.gds；Layout Map File 选刚建的 AH53_manual-layermap.txt。GDS 可直接用于工艺构建，不要求先转成 CAT。
  3. 点击 Top Cell 旁的 Scan，从扫描结果选 AH53_DEMO。Top cell 不是 GDS 文件名。
  4. Model Resolution 输入 0.02，前提是工艺单位已经确认是 µm。
  5. Model Extent 选 Single Mask，Mask=DOMAIN；或者明确选 Bounding Box：Xmin=16、Xmax=32、Ymin=−14、Ymax=14。二者选一种，不要让不同位置定义冲突范围。
  6. 如果 Wafer Setup 使用自己的 Override X-Y Extents，确保同样选 DOMAIN 或上述范围。不要让 Wafer Setup 的大范围覆盖 Manager 的小范围。
  7. 勾选 Save After Every Step，便于事后看光刻胶与每一段刻蚀；勾选 Launch Viewer After Building，方便构建后查看。
  8. 在 Manager 中 File > Save As，保存 AH53_manual.zam。依赖文件均在新目录；最后 File > Save All。

代码版 GDS 中保留了四组条纹。若这里选择 All Active Masks 而不是 DOMAIN，可能意外把计算范围扩展到四组。非理想 Multi Etch 会明显更慢。

7．六步理想工艺：逐项输入

在 Process Editor 中打开 Process Library。可双击预设步骤插入，也可以用 Add 下拉选完整步骤类型。每加一步都检查顺序、Wafer 和材料。以下第 1–5 步才是结构生成，第 6 步只是把最终结构导出。

第 1 步：Wafer Setup，建立 Si

  1. 选中第一个 Wafer Setup，名称可写 01 Si substrate 1um。
  2. Wafer Name=Wafer1；Material=/Silicon/Si_Xtal；Thickness=1.0。
  3. 范围用 DOMAIN。若界面区分默认范围与覆盖范围，只在需要时启用覆盖，并保持与 Manager 一致。
  4. 历史工程 Surface Plane=(100)、Notch Vector=<110>、Notch Design Direction=X（XML 内部名称分别为 e100、e110）。本例未做晶向选择性刻蚀，保持这些值即可。
应得到均匀 Si 板，Z≈−0.5…+0.5 µm。单组初始体积为 16×28×1=448 µm³。

第 2 步：Planar Deposit，涂 0.5 µm PR

  1. 选择 Deposition > Planar Deposit，名称 02 Coat resist 0.5um。
  2. Wafer=Wafer1，Side=Top，Material=/Organics/Resist。
  3. Thickness=0.5；Deposit type=Planarizing；Reference Plane=Highest Elevation。
  4. 这里不加 AH53_KEEP 掩模；先整面涂胶，再由下一步图形化。
Si 上方应有完整 0.5 µm 胶层，胶顶约 Z=+1.0 µm。这是几何涂胶近似，不是旋涂流体求解。

第 3 步：Expose Material，保护三条 mark

  1. 选择 Lithography > Expose Material，名称 03 Protect AH53 ridges。
  2. Wafer=Wafer1，Side=Top，Material=/Organics/Resist。
  3. Thickness=0。本步骤的 0 是“处理整层所选材料”的特殊定义，不是零厚度、没有曝光。
  4. Mask Name=AH53_KEEP；Polarity=Light。
  5. Exposed Material 留空，使曝光区域的 PR 被移除，而不是替换为另一种材料。
  6. 理想版关闭 Lithography Emulation、Edge Noise；Expose through Materials 留空（历史 XML 的 exposeThroughSolids=false）。
最关键的极性：此步骤 Light 处理 GDS 多边形外的胶，因此条纹内留胶。Dark 处理图形内，会把条纹上方的胶去掉，最终得到相反结构。不要根据“Light”字面猜胶的颜色；以阶段结果检查为准。
此时应看见三条胶条覆盖在 Si 上，外围裸露；截面上三条胶的下方仍然是 Si。

第 4 步：Straight Etch，外围刻 Si 300 nm

  1. 选择 Etch > Straight Etch，名称 04 Etch surrounding Si 300nm。
  2. Wafer=Wafer1，Side=Top，Depth=0.3。
  3. 被刻材料只选 /Silicon/Si_Xtal，相对 Etch Ratio=1。
  4. 不要把 Resist 也选为同速被刻材料。此理想步骤假设 PR 不被消耗。
  5. 不另加 AH53_KEEP 数字掩模：上一阶段留下的实体 PR 已经在保护 Si。高级额外 Mask 和 Selectivity 沿用关闭设置。
外围裸 Si 表面降至 Z≈+0.2 µm；胶下 Si 顶面保持 +0.5 µm，已经形成 300 nm 高差。胶仍然在顶上。

第 5 步：Remove Materials，去胶

  1. 选择 Utility > Remove Materials，名称 05 Strip resist。
  2. Wafer=Wafer1；Target Materials 只选 /Organics/Resist。
  3. 若有 Update Voids，保持启用。不要选中包含 Si 的上级材料组。
最终只保留 Si；mark 是凸起，顶上没有 PR。Remove Materials 是理想化删除材料，不代表实际灰化损伤或去胶残留模型。

第 6 步：Voxel Data Export，写出真正结果

  1. 选择 Save/Import/Export > Voxel Data Export，放在去胶之后，名称 06 Export final VDATA。
  2. Wafer=Wafer1；Output File 填 D:\CoventorProjects\AH53_Manual_Ideal_01\AH53_final.vdata。
  3. Export Dopants=False：本例没有掺杂。
  4. Export Plane Equations：首次对照历史文件可设 False；若计划较精细的界面重建，可设 True，但应接受文件更大。它记录现有模型的界面信息，不会提高本次 20 nm 构建分辨率。

它是工艺序列中的导出步骤。不能把 .zam 改名为 .vdata，也不是在记事本里手写三维形状。

官方：Expose Material 极性和 Thickness=0 · Voxel Data Export

8．真正运行、查看与验证结果

8.1 点击 Build，等待原生工艺求解

  1. File > Save All。切到 Manager，确认输入文件与 Top Cell、DOMAIN、0.02 µm 无误。
  2. 在 Model Builder pane 底部点 Build。若提示保存 .zam，先保存再继续。
  3. 查看构建日志，确认六个步骤依次完成。显示输入文件、导出脚本或已有截图不等于本次构建已成功。
  4. 第 6 步应明确完成 VoxelXML/VDATA 导出，且指定文件真实存在。某步报错时保留日志，不要把部分结果当作全流程成功。
  5. 以后改参数再 Build 通常可 Intelligent Restart，从改变的步骤继续。需要强制重跑时用同一 pane 的 Rebuild All。改变体素分辨率或范围通常会导致全量重建。

8.2 逐步看，而不是只看最终外观

  1. 若勾了 Launch Viewer After Building，完成后进入 Viewer。右侧 Scene pane 中选择阶段。
  2. 先看第 2 步：整面胶；再看第 3 步：条纹上留胶；第 4 步：周边硅下降；第 5 步：去胶后凸 Si。
  3. 用 View > Fit to Window 适配画面。
  4. 用 View > Enable Cross Sections；也可画布右键 Open Cross Section > Open with Y Normal，得到 X–Z 截面。
  5. 在 Cross-Section pane 的 Options > View > XZ 轴对齐；把切面移动到 Y=0。只看截面可用 View > Draw Cross-Section Plane Only。
  6. 若放大 Z 轴仅为看清 300 nm 高差，需标注显示比例。不能从经过 Z 缩放的透视截图直接估算侧壁角。

9．八步非理想工艺：逐项输入

12.1 GDS 生成

生成器以 µm 为坐标单位、1 nm 为 GDS 数据库精度，用矩形角点写 L1/D0；组中心 −24、−8、8、24，每组偏移 −3.2、0、+3.2。DOMAIN 单独写到 L99/D0。GDS 数据库精度 1 nm 不意味着最终 3D 模型或工艺预测有 1 nm 精度。

12.2 为什么读本机示例模板

9.3 的 .vproc/.zam XML 存在版本化字段。代码从安装随附的兼容示例取得步骤原型，再填入本例的材料、深度与启用项，生成新的步骤 ID 和项目路径。只改当前模型真正启用的分支；模板残留的未启用字段不能当作当前物理作用。

这些示例来自本机安装的 FinFET、PatternDependence、VDataPythonIO、DRIE_Loop 示例。教程没有捆绑厂家 SDK、许可证或整份手册；换一台机器需要合法安装对应版本与组件。

12.3 原生执行环境

控制入口使用独立子进程，配好 SEMulator3D 安装、运行库和 Python SDK 环境。旧 SDK 使用本机随附的 Python 3.6，不能把 .pyd 直接丢给任意新版 Python。ModelBuilder 的工作目录固定为本次项目目录，文件引用使用明确路径，避免历史“刻蚀成功但第 8 步找不到 .vproc”的错误。

# 核心动作的概念顺序；完整可运行实现见 code/run_process.py
生成全新项目输入
→ 启动 ModelBuilder.exe -m 本次项目.zam

保存 wafer 的随机文件名不是工艺语义。程序按步骤号定位理想第 5、非理想第 7 步，不能假定所有工程都会有同一个 xxxx.vwaf 名字。检查最终 PR 体积为 0；非理想沟底只测量并记录，不强制改成 300 nm。

12.4 导出与容器检查不是造形

VDATA 导出读取原生 wafer，不重新按参数搭建一套“看起来相同”的 CAD。文件检查解析 XML 中网格和压缩块，核对材料/占比数据规模；不会用三角化代替工艺求解。导出平面信息时也要验证该数据段确实存在。

13．怎样修改参数与设计对照

13.1 两种可靠的改法

  1. GUI 改法：先 --generate-only 生成新项目，打开 .zam，在 Process Editor 修改并 Save All，再从 Manager Build。这样参数改动来自真实 .vproc。不要随后再次执行生成器覆盖这个项目。
  2. 代码改法：复制一份教程代码到自己的新目录，在生成器中修改对应活动参数，再用新输出目录运行。长度遵守工艺单位 µm；命令行暴露的分辨率、范围和 planes 可直接用参数调整。

不要只改 parameters.json 然后期待工艺自动更新。它是生成时的记录，不是这套程序自动读取并驱动所有步骤的配方配置。运行后应同时保存真实 .vproc、.zam、日志和记录。

比较 CD、侧壁、LER、圆化与深度时，先明确测量切面和定义。20 nm 下已经出现的曲线小数不是收敛证据；如果研究 10 nm 位置误差，应另做网格与导出/转换误差分析。真实设备预测还需要用 SEM/TEM/AFM、实测刻蚀速率、选择比、图形密度测试结构去标定。

把模拟域从单组扩到四组时，loading 的上下文可能变化，不能承诺局部结果逐字节相同。也不要以“保存了完整 GDS”来声称已经跑完完整大域。

14．VDATA、界面与后续 FDTD

14.1 记事本为什么看见英文编码

.vdata 是包含 XML 元数据和压缩编码体素数据的导出容器。体素可携带材料身份与占比；可选平面方程还描述体素内界面。编码文本不是逐行可读的“X Y Z Si”清单。后缀不代表它是三角面片、STEP 实体或简单的裸 0/1 数组。

要看真实体素，应通过原生 SDK/已验证解码工具读取材料、分数、网格间距与轴顺序，或在 Viewer 切片。直接把后缀改成 .mat、.stl、.fsp 不会转换数据。

14.2 Plane Equations 应怎样选

本机历史导出是关闭的；保留材料占比不一定能唯一反推原有连续界面。后续需要尽量保留界面时，可从已保存的 wafer重新导出带 Plane Equations 的 VDATA。它会增加存储，对应信息仍受原始模型和算法限制，不创造新的物理细节；启用后也要核对下游读取器是否使用这段数据。

14.3 接上之前已经整理好的转换器

此前独立的 VDATA→Lumerical 程序目录是 D:\CoventorProjects\Coventor_VDATA_to_Lumerical。它读取真实 VDATA，支持完整几何和减面路线；本教程没有改动该纯净程序目录。

# 使用安装了转换器所需依赖的主Python环境，不是强制用旧SDK Python3.6
python "D:\CoventorProjects\Coventor_VDATA_to_Lumerical\convert_vdata.py" `
  "D:\CoventorProjects\AH53_Run_Nonideal_01\AH53_Nonideal.vdata" `
  --output "D:\CoventorProjects\AH53_Conversion_New_01" --verify-fdtd

文件名请以本次输出实际清单为准。先导出并验证形貌，再谈三角化与 QEM 减面；几何转换误差和工艺误差要分别记录。减少 CAD 面片或 .fsp 文件大小不自动等于减少 FDTD 网格数或电磁求解内存。

之后做 532 nm 光学求解，可参考此前单波长设置研究：VDATA→Lumerical 转换器仓库（FDTD 资源报告保留在原电脑）。其中 40/60 nm 只做过短时试跑和资源测量，不能当作已收敛的光学结论。本教程不自动发起新的大内存 FDTD 求解。
